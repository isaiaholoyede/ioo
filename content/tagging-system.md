# Tagging System

I use three tag layers: a domain tag, a type tag, and a status tag. Every note gets one of each.

## Layer 2 — Content Type Tags

#type/concept       $\leftarrow$ definitions, theory, explanations  
#type/derivation    $\leftarrow$ math/physics worked from first principles  
#type/proof           $\leftarrow$ formal proofs  
#type/problem-set$\leftarrow$ practice problems with solutions  
#type/project        $\leftarrow$ hands-on builds  
#type/summary     $\leftarrow$ condensed review of a topic  
#type/reference     $\leftarrow$ cheat sheets, quick lookup tables  
#type/reflection     $\leftarrow$ what you learned, lessons, mistakes  
#type/roadmap      $\leftarrow$ learning plans for a topic  

## Layer 3 — Status Tags

#status/seedling     $\leftarrow$ rough idea, just started  
#status/growing      $\leftarrow$ active notes, in progress  
#status/evergreen    $\leftarrow$ complete, stable, worth sharing  
#status/archived     $\leftarrow$ no longer active
